# PdfCraft 한국어

PdfCraft는 Rust로 만든 오픈 소스 PDF 리더·편집기입니다. PDF를 읽고, 정리하고,
결합하고, 분할하고, 보호할 수 있으며 Windows, macOS, Linux, FreeBSD와 웹에서
사용할 수 있습니다.

이 저장소에는 PdfCraft의 한국어 인터페이스 번역이 포함되어 있습니다. 앱의 언어
설정에서 `한국어`를 선택하면 메뉴, 도구, 대화상자와 상태 메시지가 한국어로
표시됩니다. 번역 카탈로그는
[`crates/ui-egui/src/i18n/ko.tsv`](crates/ui-egui/src/i18n/ko.tsv)입니다.

## 시작하기

일반적인 빌드·실행 방법은 [영문 README](README.md)의 안내를 따르세요. 한국어
번역의 추가·수정 방법은 [번역 문서](docs/localization.md)를 참고하세요.

## 라이선스와 저작자 표시

PdfCraft는 사용자의 선택에 따라 [MIT](LICENSE-MIT) 또는
[Apache-2.0](LICENSE-APACHE)으로 배포됩니다. 한국어 카탈로그의 출처와 라이선스
정보는 [ATTRIBUTION.md](ATTRIBUTION.md)와 [ATTRIBUTION.toml](ATTRIBUTION.toml)에
기록되어 있습니다.

ArtCraft 이름과 로고는 상표이며 별도 조건이 적용됩니다. 자세한 내용은
[`docs/brand/LICENSE-brand.txt`](docs/brand/LICENSE-brand.txt)를 확인하세요.

원본 프로젝트와 최신 기능 안내는 [영문 README](README.md)와
[PdfCraft GitHub 저장소](https://github.com/storytold/pdfcraft)를 확인하세요.
